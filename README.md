## Build real-world software by coding from scratch.

### Why from scratch?
A quote from Richard Feynman: “What I cannot create, I do not understand”. You should test your learning with real-world projects!

If you can build a Redis server, you can build almost any software beyond CRUD! Because it teaches you 3 fundamental skills:

1. Network programming 
The next level of programming is programming for multiple machines. Think HTTP servers, RPCs, databases, distributed systems.

2. Data structures 
Redis is the best example of applying data structures to real-world problems. Why stop at theoretical, textbook-level knowledge when you can learn from production software?

3. Low-level C
C was, is, and will be widely used for systems programming and infrastructure software. It’s a gateway to many low-level projects.
